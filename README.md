## kagari

kagari is a fork of [Flare](https://github.com/flaresocialapp/Flare)

### Features

#### App

- タブのアイコンを細かく設定
- リアクションボタンをSNSごとに設定
- どのアカウントの操作なのかを表示
- リンクカードの比率を変更

#### Bluesky

- プロフィールを編集する
- 返信・引用の設定
- メディアのモデレーション設定
- リンク・メンション・ハッシュタグに色をつける
- 長いリンクの省略
- @の後に文字を打ってメンション候補を出せる
- リプライを隠す
- 引用を外す
- ポストを固定する
- 「みつけよう」の「このような投稿を増やす・減らす」
- TOKIMEKI POLLに対応
- Madoに対応

#### pixiv

- 非公開ブックマーク
- ブックマークタグ
- 非公開フォロー
